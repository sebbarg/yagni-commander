## Packaging

- Installing from source on your own machines: `scripts/install-linux.sh` and `scripts/bundle-mac.sh` (2026-10-04). Verified by the owner (2026-10-04): the Linux install on KDE; the macOS bundle (icon in Finder and the Dock), and F4 from the viewer launching `editor = "/usr/local/bin/code"` (a full path) with the app started from the bundle; a bare `editor = "code"` did not start it there (minimal `PATH`); now fixed by `shell_path`, to check on macOS: a bare `code` from the bundle, and startup with a slow or noisy shell profile. Verified on Omarchy: the launcher entry and the icon (2026-10-04).
- Releases (decided 2026-10-04): a tag builds a universal macOS zip (ad hoc signed, not notarized; the README explains clearing the quarantine flag) and a Linux tarball with `install.sh`, published as a GitHub Release (`.github/workflows/release.yml`), plus a `curl | sh` installer (`scripts/install.sh`) for both. `bundle-mac.sh --dist` verified on the owner's Mac (universal: `x86_64 arm64`). Released as 1.0.0 (2026-10-04; the repo is public). Verified by the owner on macOS: the zip downloaded with a browser (blocked until `xattr`, as the README says) and the `curl | sh` installer (opens without a prompt). On Kubuntu (X11): the `curl | sh` installer and the tarball by hand. On Xubuntu 24.04 (X11, Xfce, in a VM): the one-liner, no extra packages. On Ubuntu 22.04 (VM, GNOME on Xorg): the one-liner after `sudo apt install curl`; the window stayed empty (see-through) with 22.04's Mesa 23.2 on llvmpipe until Mesa from the kisak PPA (README). On Fedora 44 (VM, GNOME, Wayland): native Wayland connects and falls back to client-side decorations, then llvmpipe (Mesa with LLVM 22) aborts compiling a shader ("Cannot select ... X86ISD::MGATHER"; upstream, see ghostty discussion 12037; `LP_NATIVE_VECTOR_WIDTH=128` does not help); dropped by the owner. On Omarchy (real hardware, Hyprland): the one-liner. To check: 22.04 with a real GPU. Not done, on purpose: notarization (needs a paid Apple Developer membership), `.deb` (no updates without an apt repository), Flatpak and Snap (their sandbox gets in the way of starting editors, terminals and `xdg-open` on the host).
- Later, if asked: a Homebrew tap (the official cask repo needs notability and a notarized app), an AUR `PKGBUILD`, a `.deb` via `cargo-deb`.

## v3

- **Right-click context menu** (postponed by the owner on 2026-10-03, nothing useful to put in it yet): it reuses the menu's item model and popup builder (`menus::popup`) with its own `MenuEntry` list. Open decision: whether right-click selects, as in TC's default on Linux and Windows.
- **New and updated files pulse briefly** (discussed 2026-10-02, parked). Leanings so far: every reload of the folder a panel already shows pulses (watcher, Ctrl-R, the reload after F5/F6), never a navigation or a first listing; "updated" means same name, different size or modified time (compared in `Panel::apply`); a file that keeps changing pulses about once a second. Look not decided: a background tint in a new theme role `changed`, fading out over about 1.5 s, was proposed; no pulse with reduce motion on. Drive it from a per-name timestamp, not gpui's per-element animation state, since list rows are recreated on scroll.
